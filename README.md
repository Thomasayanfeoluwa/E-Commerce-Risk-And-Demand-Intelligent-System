# E-Commerce Risk & Demand Intelligent System

This repository contains the complete engineering project that engineers raw CSV data to analysis, machine learning, model validation, API development, database logging, frontend integration, deployment, documentation, and post-deployment monitoring.

## Folder Structure

- `data/` - Canonical data files
- `notebooks/` - Jupyter notebooks for EDA and model blueprints
- `docs/` - Project documentation and analysis notes
- `kaggle/` - Kaggle-specific metadata
- `archive/` - Experimental or deprecated work
